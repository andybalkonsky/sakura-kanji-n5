# さくら漢字 · Sakura Kanji N5

Отдельный тренажёр кандзи с русскими переводами, созданный на основе интерфейса [Kotoba](https://github.com/andybalkonsky/kotoba-japanese-trainer).

## Открыть приложение

**https://andybalkonsky.github.io/sakura-kanji-n5/**

## Установить на телефон

- **Android:** откройте ссылку в Chrome и выберите «Установить приложение» в меню браузера. Если браузер предлагает установку внутри приложения, можно нажать кнопку «Установить».
- **iPhone:** откройте ссылку в Safari, нажмите «Поделиться» → «На экран Домой».

После первого открытия приложение работает без интернета. Прогресс хранится в браузере или установленном приложении; для переноса используйте «Ещё» → «Экспортировать прогресс» и «Импортировать прогресс».

## Возможности

- Кандзи → русский перевод и русский перевод → кандзи, по четыре варианта ответа.
- Кнопка «Подсказка» показывает чтение хираганой.
- Наборы: 110 отдельных знаков, слова с кандзи, все 641 написание.
- Занятия по 10, 20, 30 карточек или всему доступному набору, со случайным порядком.
- Интервальное повторение, повторение ошибок, избранное, поиск и статистика.
- Нежно-розовая тема, адаптивная компоновка и установка как веб-приложения.

## Словарь

Объединены `Vocab_N5(1).pdf` (715 строк исходного словаря) и `JLPT_N5_110_sakura_fold_cards(2).pdf` (110 знаков). После отбора записей с кандзи и объединения повторов осталось **641 уникальное написание**. Разные чтения и значения одного написания объединены. Записи только на кана исключены. Это учебные списки источников, а не официальный перечень JLPT.

У отдельных знаков чтение может быть основой слова, а не самостоятельным словом. Например, おお в 大きい. Исправленный Excel из предыдущего чата не использован: его файл был недоступен. Запись 元気 с чтением げんき и переводом «бодрость, хорошее настроение, здоровье» извлечена из PDF.

## Публикация и запуск

Зависимости и сборка не нужны. GitHub Pages публикует ветку `main`, папку `/ (root)`. Для локального запуска достаточно статического веб-сервера. Установка и офлайн-режим работают на HTTPS или localhost.

`index.html` — интерфейс, `app.js` — логика и сохранение прогресса, `data.js` — словарь, `style.css` — оформление, `manifest.webmanifest` и `sw.js` — установка и офлайн-режим.

При обновлении ресурсов меняйте версию кэша в `sw.js`. Данные этого приложения хранятся отдельно от Kotoba.
